# Evaluation cases

`cases.json` tests activation, evidence discipline, contribution calibration, and the boundary between seminar advice and official journal policy.

A case passes when every expected behavior is materially present and the response introduces no unsupported study fact, result, citation, speaker claim, or journal requirement. Rewrites must not increase evidential strength beyond the supplied design and findings.

For manuscript-level evaluation, use only author-provided or newly created text. Keep unpublished papers under ignored private paths and record whether the task is diagnosis, planning, rewriting, or independent review.
