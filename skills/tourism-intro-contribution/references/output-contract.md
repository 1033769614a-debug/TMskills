# Output contract

## Full diagnosis

Return five clearly distinguishable components:

1. **Argument in one sentence** — what the introduction currently asks the reader to believe.
2. **Claim-to-evidence map** — problem, conversation, gap, research response, findings, and contribution; label each as supported, incomplete, overstated, or missing.
3. **Priority diagnosis** — no more than the most consequential issues unless the user requests an exhaustive review.
4. **Revision** — preserve the study's actual design and findings; never create citations, results, mechanisms, or novelty.
5. **Audit note** — identify which recommendations come from the verified lecture method, independent evidence, journal requirements, or general editorial judgment.

## Quick assessment

When the user asks for a fast check, return:

- strongest element;
- main credibility problem;
- single highest-value revision;
- evidence still needed.

## Contribution calibration

Separate demonstrated contribution from aspiration. If the available evidence supports only a contextual extension, measurement contribution, replication, boundary condition, or practical implication, do not relabel it as a major theoretical contribution.
