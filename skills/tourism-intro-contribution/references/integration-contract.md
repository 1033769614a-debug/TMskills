# Multi-skill integration contract

Use this order when the user requests an end-to-end paper workflow:

1. **Tourism introduction and contribution skill** — diagnose argument architecture and calibrate contribution claims.
2. **Literature/citation workflow** — verify the conversation, gap, and factual claims with appropriate sources.
3. **Academic drafting workflow** — implement the agreed structure and evidence map.
4. **Language polishing workflow** — improve clarity and style without strengthening claims.
5. **Independent reviewer workflow** — challenge necessity, novelty, evidence, and fit without seeing a preferred verdict.

At each handoff, preserve:

- the study's actual research question, design, findings, and limitations;
- a list of verified versus unverified citations;
- provenance labels for lecture guidance, journal policy, external literature, and author decisions;
- unresolved evidence gaps.

Do not allow a later workflow to silently override an earlier evidence boundary. If skills conflict, follow the user's explicit instruction and verified target-journal requirements, then report the conflict.
