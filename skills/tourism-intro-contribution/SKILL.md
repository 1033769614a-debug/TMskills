# Tourism Introduction and Contribution

Apply the webinar-derived method as a manuscript-reasoning workflow, not as a generic style guide or as official journal policy.

## Source gate

Read [references/source-register.md](references/source-register.md) first.

- If its status is not `VERIFIED`, explain that the lecture-derived method has not yet been ingested and do not attribute rules to the speaker or journal. Ordinary writing help may continue only if the user asks for it without claiming this skill's authority.
- When the status is `VERIFIED`, read [references/lecture-method.md](references/lecture-method.md) before diagnosing or rewriting.
- When the user asks about public provenance, the event recap, the replay, or whether advice is official policy, also read [references/public-event-recap.md](references/public-event-recap.md).
- Never present seminar advice as a formal requirement of *Tourism Management* unless an independently verified journal source establishes that requirement.

## Inputs

Use the material the user actually supplies. Seek only missing facts that would materially change the diagnosis:

- target outlet and manuscript type;
- current introduction, abstract, or contribution passage;
- research question, design, principal findings, and claimed contribution;
- literature already used to establish the problem or gap;
- requested language and whether the task is diagnosis, planning, rewriting, or review.

Do not infer findings, novelty, causal strength, generalizability, or theoretical contribution from topic alone.

## Workflow

1. Identify the manuscript's intended problem, conversation, gap, research response, findings, and contribution.
2. Build a claim-to-evidence map. Mark unsupported, overstated, circular, or merely contextual claims.
3. Apply the verified webinar criteria and examples. Preserve distinctions between speaker guidance, published evidence, journal requirements, and the user's own decisions.
4. Give the diagnosis before rewriting. Prioritize the few changes that most improve necessity, logical continuity, and contribution credibility.
5. Rewrite only within the available evidence. Keep uncertainty and limitations visible.
6. Audit the result against [references/output-contract.md](references/output-contract.md). State unresolved evidence gaps instead of masking them with stronger prose.

## Coordination with other skills

When other skills are used, keep ownership clear. Read [references/integration-contract.md](references/integration-contract.md) for a multi-skill paper workflow.

- This skill owns introduction logic, gap quality, and contribution calibration.
- A literature or citation skill owns searching and verifying external evidence.
- A drafting skill may implement the agreed structure.
- A polishing skill may improve language without changing claims.
- A reviewer skill should independently challenge the revised argument after drafting.

The user's explicit instructions and verified target-journal requirements take priority over webinar-derived guidance.

## Output

For substantive work, provide:

1. a concise diagnosis;
2. a claim-to-evidence table or equivalent mapping;
3. a prioritized revision plan;
4. the requested revised text, if authorized;
5. unresolved questions, missing evidence, and provenance labels.

Use the shorter form in [references/output-contract.md](references/output-contract.md) when the user requests only a quick assessment.
